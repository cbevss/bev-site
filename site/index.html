BEV for Windows

The BEV dashboard in its own window, with a Start menu entry, a desktop shortcut and a taskbar icon. It always shows the newest version of the site, and the app updates itself when there's a new version.

  1. Press Install the app to download BEV-Setup.exe (about 1 MB).
  2. Open it. It downloads BEV, installs it and opens it. No admin rights needed.
  3. Sign in with Discord, just like on the website.
Install the app

If Windows says “Windows protected your PC”, press More info, then Run anyway. Windows shows this for apps that aren't signed with a paid certificate yet. For Windows 10 and 11 (64-bit). Uninstall from Settings → Apps.

Before you click

Who can add BEV

Anyone with the Manage Server permission on a server. If that isn't you, send this page to someone who has it.

What BEV asks for

BEV asks for the Administrator permission so it can create channels and roles, moderate members and run its protection features. Discord shows the full list before you confirm.

Only admins control it

Every command that changes your server is for server admins only, and the dashboard only lets you change servers you are an administrator of.

Questions people ask

Is BEV free?

Yes. Every feature in BEV is free to use: protection, moderation, welcomes, role menus, levels, the economy and casino, music, tickets, stream alerts and the web dashboard.

Can BEV replace several bots in one server?

Yes. BEV is an all-in-one Discord bot: anti-nuke and anti-raid protection, AutoMod and AI moderation, logs, tickets, welcome cards, reaction and button role menus, leveling with role rewards, an economy with a shop and casino games, giveaways, polls, events, Twitch, YouTube and Kick live alerts, a music player and server backups, all set up from one dashboard.

Does BEV protect against nukes and raids?

Yes. Anti-Nuke stops admins or bots that delete channels and roles or mass-ban, Anti-Raid locks the server when lots of accounts join at once, and BEV also has a scam link blocker, a honeypot trap channel, alt account detection, verification with a captcha and automatic server backups you can restore.

How do I set BEV up?

Add BEV to your server, sign in on bevbotdiscord.com with Discord, pick your server on the dashboard, switch on the features you want and press Save. The Server Builder can also create ready-made categories and channels for you.

Does BEV need the Administrator permission?

BEV asks for Administrator so it can create channels and roles, moderate members and run its protection features. Only server admins can change BEV's settings.
