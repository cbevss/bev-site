BEV for Windows

The BEV dashboard in its own window, with a Start menu entry, a desktop shortcut and a taskbar icon. It always shows the newest version of the site, and the app updates itself when there's a new version.

  1. Press Install the app to download BEV-Setup.exe (about 1 MB).
  2. Open it. It downloads BEV, installs it and opens it. No admin rights needed.
  3. Sign in with Discord, just like on the website.
Install the app

If Windows says “Windows protected your PC”, press More info, then Run anyway. Windows shows this for apps that aren't signed with a paid certificate yet. For Windows 10 and 11 (64-bit). Uninstall from Settings → Apps.

Before you click

Who can add BEV

Anyone with the Manage Server permission on a server. If that isn't you, send this page to someone who has it.

What BEV asks for

BEV asks for the Administrator permission so it can create channels and roles, moderate members and run its protection features. Discord shows the full list before you confirm.

Only admins control it

Every command that changes your server is for server admins only, and the dashboard only lets you change servers you are an administrator of.
