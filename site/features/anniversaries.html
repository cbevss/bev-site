🎉 Member Anniversaries

Celebrates each member's join anniversary every year: a message in your channel, coins if you like, and a role for reaching each year.

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Where to celebrate (a channel)
  • Message (text)
    Placeholders: {user}, {name}, {server}, {years}
  • Coins to give (0 for none) (a number)
  • Roles for each year (a list)
    Like 1 year → @Veteran. Members keep the roles for every year they've reached
    Each one has (up to 10):
    • Years
    • Role
