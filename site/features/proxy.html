🎭 Roleplay Characters

For roleplay: members save characters with a name, picture and tag (like k:) using /roleplay → Add. A message that starts with the tag is reposted as that character. Right-click a reposted message → Apps → Who posted this? shows who wrote it. BEV needs Manage Webhooks.

Also known as: roleplay tupper character proxy RP characters webhook characters

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Only in these channels (channels)
    Leave empty to allow it everywhere

Commands

  • /roleplay: Post as roleplay characters: save a character with a tag, then start messages with that tag.
    • Add button: Save a character. Messages starting with its tag are reposted as it.
    • List button: See your saved characters and their tags.
    • Remove button: Delete one of your characters.
