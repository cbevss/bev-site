🔗 Anti-Link Filter

Removes links that members post, so nobody can spam invites, scams or ads. Allow certain websites, or only block Discord invites.

Also known as: link blocker invite blocker block Discord invites anti-advertising

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • What to block (a choice)
    Choices: All links, Only Discord invites
  • When a link is found (a choice)
    Choices: Delete the message, Delete and warn them, Delete and time out for 10 minutes
  • Allowed websites (a list of words)
    Websites members may still link to
  • Channels where links are fine (channels)
    Links are never removed here
  • Roles that may post links (roles)
    Members with these roles can post links
  • Test mode: only log what BEV would do (on/off)
    Nothing is deleted and nobody is punished. Each match goes to your log channel, so you can tune the settings first
