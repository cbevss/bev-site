🪪 BEV's Look in This Server

Give BEV its own nickname, profile picture, banner and About Me in this server only, so it matches your server's style. Switch it off to put BEV's normal look back.

Also known as: custom bot name custom bot avatar per-server bot profile white label bot nickname custom branding

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Nickname (text)
  • Profile picture (link) (text)
    A link to a picture. GIFs move. Up to 8 MB.
  • Banner (link) (text)
  • About Me (text)
