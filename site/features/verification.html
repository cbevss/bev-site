✅ Member Verification

New members get the Unverified role and must pass a check to get Verified: a button, a maths question or a picture code. Hide your channels from @everyone and show them to Verified.

Also known as: verify captcha verification gate member screening verified role

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Check type (a choice)
    Choices: Press a button, Answer a maths question, Type the code from a picture
  • Verify channel (a channel)
  • Category for the channel BEV makes (a channel)
    If BEV makes this feature's channel (when none is picked), it goes in this category. Leave it empty for the top of the server.
  • Role after verifying (a role)
  • Role while waiting (a role)
  • Picture code: length (a choice)
    How many characters the picture code has. Only used when the check type is a picture code.
    Choices: 4 characters, 5 characters, 6 characters, 7 characters, 8 characters
  • Picture code: colours (a choice)
    Black and white is easier for people with colour blindness.
    Choices: Colourful letters, Black and white (easiest to read)
  • Picture code: lines across it (a choice)
    Lines drawn over the code to confuse bots. More lines make it harder for people to read too.
    Choices: None, A few, Some, Lots (hardest for bots)
  • Picture code: capitals must match (on/off)
    When on, the code mixes capital and small letters and they must be typed exactly.
  • Picture code: use numbers too (on/off)
    When off, the code only has letters.
  • Time to answer (a choice)
    How long a maths question or picture code stays valid before they have to press Verify again.
    Choices: 1 minute, 2 minutes, 5 minutes, 10 minutes
