⛓️ Jail

Takes a member's roles away and keeps them in one jail channel until staff release them, then gives everything back.

Also known as: jail quarantine mute role timeout channel isolation

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Jail role (a role)
  • Jail channel (a channel)
  • Category for the channel BEV makes (a channel)
    If BEV makes this feature's channel (when none is picked), it goes in this category. Leave it empty for the top of the server.
  • Give back the roles they had before (on/off)
    When someone is released. Off: they only get the roles below
  • Roles to give when released (roles)
    Optional, for example Member or Reformed
  • Reset their level and XP when jailed (on/off)
    They go back to level 0 with no XP, and lose their level reward roles. The reflection message tells them
  • Let people in jail ask to be freed (on/off)
    Their first message in the jail channel is deleted and sent to Requests to be freed on this card for staff to approve or deny. Anything else they send there is deleted
  • Tell staff about new requests in (a channel)
    Optional. BEV posts each new request here with a link to review it. Empty: it goes in the Moderation Logs
  • Roles to ping for new requests (roles)
    Optional, for example Moderators and Admins. All of them are pinged with each new request
  • Reflection message (text)
    Posted in the jail channel with the button on this card. Use {server} for the server's name

Commands

  • /jail: Lock a member in a jail channel without their roles, then free them with roles back.
