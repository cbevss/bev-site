🕵️ Snipe

/snipe shows the last deleted message in a channel. Off by default because it's less private.

Also known as: snipe deleted messages edit snipe

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Commands

  • /snipe: Show the last deleted message in this channel.
