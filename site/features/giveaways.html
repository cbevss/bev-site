🎁 Giveaways

Run giveaways: members press a button to enter and BEV picks the winners when the timer ends. Reroll winners or end early any time.

Also known as: giveaway raffle contest prize draw

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Roles to ping for giveaways (roles)
  • Default giveaway channel (a channel)

Commands

  • /giveaway: Start, end and reroll giveaways that members enter with a button.
