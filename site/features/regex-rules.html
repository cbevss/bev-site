🧪 Advanced AutoMod Rules

Your own filters written as regular expressions (patterns), with how many matches it takes, how fast, and what happens. For words, the Word Filter is simpler.

Also known as: regex filter custom patterns advanced word filter

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Rules (a list)
    Each one has (up to 25):
    • Rule name
    • Pattern (regular expression)
    • Then (Tell the staff only, Delete the message, Delete and warn, Delete and time out, Delete and kick, Delete and ban)
    • After how many matches
    • Within (minutes)
    • Timeout minutes
    • Roles it doesn't apply to
