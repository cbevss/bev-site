🎁 Claim Button

Post a message with a button. Pressing it gives each person a message only they can see: the same one for everyone, or a different one each from a list you give (each handed out once). Choose who can claim and whether it's once per person.

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Channel to post in (a channel)
  • Title (text)
  • Message (text)
  • Colour (text)
  • Picture (optional) (text)
  • Button text (text)
  • Button emoji (text)
    One emoji, or leave it empty.
  • Button colour (a choice)
    Choices: Green, Blue, Grey, Red
  • What people get (a choice)
    Choices: The same message for everyone, A different message each, from a list (each one given once)
  • Message they get (text)
    Only the person who pressed the button sees it. {user} is their name.
  • Messages to give out (one per line) (text)
    Each person gets the next unused line. Add more lines any time; lines already given out are never given again.
  • Once per person (on/off)
  • Who can claim (roles)
    Leave empty to let everyone claim.
  • Send it (a choice)
    Choices: As a message only they can see, In a DM
  • If they've already claimed (text)
  • When they've all gone (text)
  • If they don't have a role that can claim (text)
