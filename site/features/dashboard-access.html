🔑 Dashboard Access

Lets people who aren't admins use this server's dashboard: pick a role or members, then what they can see and change. The server owner can also choose who else manages this card, and take parts away from anyone, admins included.

Also known as: dashboard permissions staff dashboard access web panel access

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.
