💎 Booster Role

BEV gives this role to everyone boosting the server and takes it away when they stop. Discord's own Server Booster role can't be handed out by bots, so this one is yours to colour and use for perks. If no role is picked, switching this on makes a pink one called Booster.

Also known as: booster role custom booster role Nitro booster perks

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.
