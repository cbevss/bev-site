🧷 Channel Modes

Give channels special behaviour: start a thread on every post, allow only pictures and videos, or keep a sticky message at the bottom.

Also known as: sticky messages media only channel image only auto thread slowmode per channel

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Channel rules (a list)
    Each one has (up to 25):
    • Channel
    • Mode (Auto-thread every post, Media only, Sticky message)
    • Sticky text or thread name
