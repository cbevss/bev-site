🤖 Discord AutoMod Rules

Sets up Discord's own AutoMod for you. It blocks words, invites and mention spam before the message is even sent, and keeps working while BEV is offline.

Also known as: AutoMod auto moderation Discord AutoMod rules keyword filter

A free BEV dashboard feature

Switch it on and set it up on the BEV dashboard. Everything below can be changed there, with a preview before anything is posted.

Settings

  • Words Discord should block (a list of words)
  • Block Discord invites (on/off)
  • Mention limit per message (a choice)
    Choices: No limit, 5 mentions, 8 mentions, 10 mentions, 15 mentions, 20 mentions
  • Use Discord's spam detection (on/off)
  • Alert channel (a channel)
    Discord posts blocked messages here
