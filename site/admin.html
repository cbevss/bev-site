Connect the site database

Maintenance mode, the banner and visit counts are saved in a small Cloudflare database that isn't connected yet. Everything else on the site works.

  1. In Cloudflare, open D1 SQL database (under Storage & databases in the sidebar) and press Create Database. Any name works, like bev-site.
  2. Open Workers & Pages → this site → Settings → Bindings → Add → D1 database. Set the variable name to SITE_DB and pick the database.
  3. Upload the site again under Deployments → Create deployment, because Cloudflare only applies bindings to new uploads.
